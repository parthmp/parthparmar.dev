# Parth Parmar - Portfolio

Personal portfolio website showcasing my work, projects, and experience as a Full-Stack Developer.

**Live Site:** [parthparmar.dev](https://parthparmar.dev)

## Overview

This portfolio site is built with **Nuxt 4 + Vue 3** using SSG (Static Site Generation). It showcases reusable component architecture, composable patterns, dynamic routing, and optimized image delivery with NuxtPicture - all wrapped in thoughtful UI/UX with excellent performance. **The code itself is a portfolio piece.**

## Features

- 📄 **Multiple Portfolio Pages** - Dedicated pages for each major project (DeskMint, and 4-5 other portfolio pieces)
- 🎨 **Custom Components** - Modular component architecture for content management
- 🖼️ **Custom OG Image Component** - Dynamic Open Graph images for social sharing
- 🔍 **SEO Optimized** - Comprehensive meta tags, structured data, and semantic HTML
- 🖼️ **Custom Lightbox** - Built-in image lightbox component for project showcases
- ⚡ **Performance Focused** - Optimized images, lazy loading, and minimal JavaScript
- 📱 **Fully Responsive** - Mobile-first design approach
- 🎯 **SSG Deploy** - Pre-rendered static pages for fast loading

## Tech Stack

- **Framework:** Nuxt 4
- **Frontend:** Vue 3 (Composition API)
- **Styling:** Tailwind CSS
- **Image Optimization:** NuxtPicture
- **Build Mode:** SSG (Static Site Generation)

## Installation & Setup

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Clone & Install

```bash
# Clone the repository
git clone https://github.com/parthmp/parthparmar.dev
cd parthparmar.dev

# Install dependencies
npm install
```

### Development

```bash
# Start development server at http://localhost:3000
npm run dev
```

### Build for Production

```bash
# Generate static site
npm run generate
```

## Custom Components

### OG Image Component
Custom-built component for generating dynamic Open Graph images for social media sharing. Each page has tailored OG images for better social media presence.

### Lightbox Component
Custom image lightbox for showcasing project screenshots and visuals without external dependencies.

### Modular Content Components
Reusable components designed to manage and display content efficiently across multiple portfolio pages.
